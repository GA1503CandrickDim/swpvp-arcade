✦ WRAITH SKIN VAULT

Collect cosmetic character looks for the games. Purchases use your existing in-game Molecules balance — except the Sigilized Devil skin, which is 250 Atoms or 125 Ions. Skins do not increase damage, health, speed, rewards, or competitive stats.

How it works

  • Earn Molecules by playing supported games.
  • Buy a skin once and keep it in your local game collection.
  • Equip or switch skins at any time from the shop.
  • Skin selection emits a shared event so each game's character renderer can display its matching art.
  • Atom and Ion balances are only read (and spent, on a Sigilized Devil purchase) — no other ATOMS, ION, wallet-linking, save, or real-money system is modified.

This first integration provides the shared shop, ownership, and equip layer. Individual game character renderers still need their own art adapters before every character model visibly changes.
